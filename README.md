# Milad Ansari — Portfolio

Static personal portfolio intended for deployment at `https://milladansari.github.io`.

## Deploy to GitHub Pages

1. Create a public GitHub repository named **`MilladAnsari.github.io`** under the `MilladAnsari` account.
2. Copy this directory's contents to the repository root, commit, and push to the `main` branch.
3. In GitHub, go to **Settings → Pages** and set **Source** to **Deploy from a branch**, then select `main` and `/(root)`.

GitHub will publish the site at `https://milladansari.github.io` within a few minutes.

## Files

- `index.html` — page content and accessible structure
- `styles.css` — responsive dark-first design system and light theme
- `script.js` — theme persistence, mobile navigation, reveal transitions
- `assets/Milad_Ansari_CV.pdf` — downloadable CV
